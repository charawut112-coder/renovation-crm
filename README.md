# BUILDSPACE CRM — MVP รีโนเวทบ้าน + หลังการขาย

เว็บแอปทีมงานรีโนเวทบ้านปริมาณมาก (ตั้งแต่ 10 หลังต่อเดือน) อ่านข้อมูลตั้งต้นจาก snapshot ของ Google Sheet `BUILDSPACE_data` และยังคงโมดูลขายของเฟสก่อน (Pipeline 9 สถานะ, ลีด, Lead Agent, Warranty)

## รันบนเครื่อง

```bash
npm install
npm run dev
```

เปิด http://localhost:3000

ตรวจบิลด์:

```bash
npm run build
```

## ห้าหน่วยงาน

บ้านทุกหลังเป็นระเบียนเดียวกัน งานขยับด้วยการเปลี่ยนหน่วยงาน ไม่ได้ก็อปปี้ข้อมูล:

1. งานออกแบบ — บอร์ด ร่าง → รอตรวจ → แก้ไข → อนุมัติ
2. งานก่อสร้าง — บอร์ดขั้นงาน, คิวช่าง, ความคืบหน้าและรูป
3. งานขาย — ลูกค้า, ลีด, ข้อตกลง, ส่งมอบ
4. งานบริการหลังการขาย — แจ้งซ่อม, รับประกัน, ติดตาม, นัดช่าง, ปิดงานแบบยืนยัน
5. สต็อกวัสดุและจัดซื้อวัสดุ — วัสดุ, การเคลื่อนไหว, ใบสั่งซื้อ, ต้นทุนรายบ้าน (เบิกออกได้เฉพาะบ้านที่อยู่ในงานก่อสร้าง)

ปุ่ม «ส่งต่อไปหน่วยถัดไป» ตรวจเงื่อนไขก่อนเปลี่ยนหน่วย และเก็บบันทึกที่เปิดดูได้จากทุกหน่วยงาน

- ออกแบบ → ก่อสร้าง ได้เมื่อแบบอนุมัติ หรือระบุว่าไม่ออกแบบ
- ก่อสร้าง → ขาย ได้เมื่อขั้นงานถึง «ตรวจงานก่อนนำขาย»
- ขาย → หลังการขาย ได้เมื่อสถานะขายเป็นตกลงหรือส่งมอบแล้ว และยืนยันส่งมอบหรือมีใบส่งมอบ

แดชบอร์ดสรุปจำนวนและจุดติดของทุกหน่วย AI Agent ตอบข้ามหน่วยจากข้อมูลชุดเดียวกัน

## หน้าที่มี

- แดชบอร์ด — จำนวนบ้านตามหน่วย, จุดติด, งานล่าช้า, สต็อกถึงจุดสั่งซื้อ
- งานออกแบบ / งานก่อสร้าง / งานขาย / หลังการขาย / สต็อก — พื้นที่ทำงานของแต่ละหน่วย
- ลูกค้าและบ้าน — ระเบียนร่วม, กรองตามหน่วยงานได้
- สถานะงานและคิวช่าง — เครื่องมือของงานก่อสร้าง
- ลีด, ข้อตกลง, ส่งมอบ, Lead Agent — เครื่องมือของงานขายจากเฟสก่อน
- AI Agent — แชทสรุปงานค้าง, ค้นประวัติบ้าน, แยกตามหน่วยงาน

การแก้ข้อมูลในหน้าจอเก็บในเบราว์เซอร์ (localStorage) ทับบน snapshot ไม่มีฐานข้อมูลในรอบนี้

## อัปเดต snapshot

1. ส่งออก JSON จาก Google Sheet `BUILDSPACE_data` (สเปรดชีตอ้างอิง `1OMqr19HmZ2IGT07z8OB3jhillsTS35gjqt2i0hQbyuY`) ให้โครงเหมือนไฟล์เดิม: `sheets` แล้วแต่ละชีตมี `headers` กับ `rows`
2. ชีตที่ใช้: โครงการ, สถานะบ้าน, งานออกแบบ, Aftersell ปรับปรุง, ช่าง, วัสดุ, สต็อก, รายการเคลื่อนไหว, รายการสั่งวัสดุ, สถานะสั่งของเข้าหน้างาน
3. ห้ามใส่ชีตผู้ใช้ระบบ, รหัสผ่าน, salt หรือแฮชรหัสลงในไฟล์
4. แทนที่ `data/buildspace-snapshot.json` แล้วรัน `npm run dev` ใหม่
5. ถ้าต้องการทิ้งรายการที่กดบันทึกค้างในเบราว์เซอร์ ให้กด «ล้างข้อมูลที่บันทึกในเบราว์เซอร์» บนแดชบอร์ด
